# Contributing to the Bidirekt TypeScript SDK

## Bugs and feature requests

Open an issue in this repository, with the **Bug report** or the **Feature request** form.

## Questions

For questions about using Bidirekt, read the docs at https://bidirekt.com/docs.

## Pull requests

Fork the repository, create a branch, and open a pull request against `main`. The CI checks `check`, `lint`, `typecheck`, `test` and `e2e` must pass before it is merged. Run the first four locally, from the repository root, with `npm run check`, `npm run lint`, `npm run typecheck` and `npm test`.

## Security

Report a vulnerability as [SECURITY.md](SECURITY.md) describes, never in an issue.
